
# Assignment 2 - Express Portfolio Website

## Project Description

This is my personal portfolio website.

The website uses Node.js, ExpressJS, EJS, Bootstrap,
and Font Awesome.

## Website Pages/Sections

1. Home: Introduction and profile picture.
2. About Me: Information about me and my skills.
3. Projects: My introduction video and graphic design poster.
4. Contact Me: A link to contact me by email.

## Technologies Used

Node.js, ExpressJS, EJS, HTML5, CSS, Bootstrap, Font Awesome

## Project Structure

- app.js: Main Express application configuration.
- routes/index.js: Routes for the four portfolio pages.
- views/: EJS templates for each page.
- views/partials/: Shared header and footer.
- public/images/: Portfolio images.
- public/videos/: Introduction video.
- public/stylesheets/: Website CSS.
